## [0.1.0] - 2026-08-18

- Added the workspace-scoped API, resumable-safe upload state, background jobs,
  immutable recordings, annotations, bad-channel review, QC, processing, exports,
  memberships, audit events, and coarse workspace metrics.
- Added EDF/EDF+, BDF, BrainVision, EEGLAB, FIF, configured CSV, and BIDS
  interoperability foundations with checksum-pinned public acceptance data.
- Added the bounded Canvas waveform viewer, sample path, import wizard, keyboard
  navigation, responsive layouts, and complete browser acceptance flow.
- Added Compose services, non-root container definitions, migrations, CI, scheduled
  public-data validation, documentation, and Apache-2.0 licensing.
