# Archive

Superseded planning, milestone, and pre-launch process documents, kept for
project history. Nothing in this directory should be treated as describing
the current architecture, current deployment shape, or current product
status — see the top-level [docs/](..) directory and the main
[README.md](../../README.md) for what's current.

| Document | Why it's archived |
|---|---|
| `ALPHA_READINESS_REPORT.md` | Point-in-time readiness snapshot predating the S3-backed storage migration and the Kubernetes/performance/runtime validation work |
| `ALPHA_USER_OUTREACH.md` | A staged user-recruiting plan for a specific alpha-launch phase |
| `ASSUMPTIONS.md` | Notes from the project's initial bootstrapping, before the current repository structure existed |
| `FIRST_USER_AUDIT.md` | A dated, point-in-time audit report |
| `MILESTONE_REPORTS.md` | Milestone evidence tied to the same superseded architecture as `ALPHA_READINESS_REPORT.md` |
| `OPEN_SOURCE_STRATEGY.md` | Go-to-market/positioning notes, not technical documentation |
| `PERFORMANCE_VALIDATION.md` | Superseded by `../PERFORMANCE.md`, which measures the current S3-backed stack |
| `PRODUCT_MEDIA.md` | Screenshot-capture process notes for a specific release |
| `PUBLIC_ALPHA_DEPLOYMENT.md` | Described a "managed container platform without Kubernetes" deployment shape that predates and conflicts with the Helm/Kubernetes path in `../DEPLOYMENT.md` |
| `PUBLIC_ALPHA_SECURITY_REVIEW.md` | A dated, point-in-time security review |
| `ROADMAP_FREEZE.md` | A one-time directive tied to a specific launch decision |
| `SPEC_REVIEW.md` | A pre-implementation specification review |
| `TEST_PLAN.md` | Superseded by the actual test suite and `../REAL_DATA_TEST_PLAN.md` |
| `USER_READY_ALPHA_PLAN.md` / `USER_READY_ALPHA_REPORT.md` | A dated launch plan and its corresponding report |
| `USER_TESTING_PLAYBOOK.md` | A user-research process document |

If you're looking for current, authoritative documentation, start at the
[documentation index in the README](../../README.md#documentation).
